# 지도와 라이브러리

지도 경계는 Natural Earth 국가 데이터(world-atlas 2.0.2)와 U.S. Census Bureau 주 경계(us-atlas 3.0.1)에서 생성했습니다. 수집 프로그램이 실행되는 동안 지도는 바뀌지 않으며 도시 중심 좌표만 사용합니다. 날짜변경선에서 도형을 분리하고 메르카토르 표시 범위 밖 좌표를 제한했습니다. 국경·행정구역 표시는 공식 법적 경계 판정이 아닙니다.

- Natural Earth: https://www.naturalearthdata.com/about/terms-of-use/ (public domain)
- world-atlas: https://github.com/topojson/world-atlas (ISC)
- us-atlas: https://github.com/topojson/us-atlas (ISC)
- MapLibre GL JS: BSD-3-Clause
- Apache ECharts: Apache-2.0
- React: MIT

각 의존성의 정확한 라이선스 전문은 설치 패키지에 포함되어 있습니다. 외부 지도 타일이나 유료 지도 API는 사용하지 않습니다.
