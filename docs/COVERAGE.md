# 일일 점검 범위와 실제 수집

미국 **50개 주 + Washington, D.C.**의 공식 출처 목록을 빠짐없이 등록했습니다. `data/jurisdictions-a-m.json`, `data/jurisdictions-mt-wy.json`에서 기관·실제 URL·자료 범위·조사 한계를 수정할 수 있습니다. 현재 자료는 AV 프로그램·공식 법령·제도·허가 명단·공식 발표가 혼재합니다. 각 주가 같은 통계를 공개한다고 가정하지 않습니다.

## 실제 연결한 경로

| 자료 | 자동 작업 | 집계 기준 |
|---|---|---|
| TxDMV 공개 TruckStop JSON | 페이지 순회, VIN 대문자 정규화·중복 제거, 차종 별칭 정규화, 원본 총계 대조 | 텍사스 전체 등록부. 도시 배정·영업과 다름 |
| FSD Database 공개 JSON | 동일 텍사스 등록부의 민간 집계·차종 합계 대조 | 민간 재집계, 독립 원출처 아님 |
| Pioneerlands 공개 지역 집계 | Robotaxi Tracker 커뮤니티 명부를 재게시한 공개 집계 수집 | 관측 명부. 배치·상업운행·30일 전체 가동 대수가 아님 |
| Tesla 공식 안전 페이지 내장 JSON | Coming Soon 목록과 검증된 지리 사전 일치 시 계획 지역 추가 | 계획 발표. 주행거리는 차량 수로 변환하지 않음 |
| 미국 51개 공식 AV 관련 문서 | HTTP 응답·본문/PDF 검증·내용 해시 변경 감지 | 문서 확인. 대부분 차량 수 의미 추출은 미연결 |
| 알려진 영국·런던·서울 공식 자료 | 일반 자율주행 제도 문서 변경 감지 | Tesla 진출·운영 여부를 증명하지 않음 |
| Google News 영문·한국어 / Bing News RSS | 전 세계 Tesla Robotaxi/Cybercab 소식 후보 탐색·중복 ID·최초 발견일 보존 | 원문 검토 후보. 제목으로 차량 수·허가·영업을 확정하지 않음 |

대화의 웹 검색 도구는 GitHub Actions에 제공되지 않습니다. 위 수집기는 공개 HTTP·RSS만 사용하며 API 키나 유료 검색 서비스가 필요 없습니다. 모든 국가·언어·모든 기관의 소식을 망라하지는 않습니다.

## 차량 수와 시각

TxDMV 공식 [차량 원본 화면](https://txmccs.txdmv.gov/truckstop/companies/81edcff1-8a6e-4ed0-be1f-60668515e223/automated-motor-vehicles)의 공개 API를 정상 브라우저 번들에서 확인했습니다. 기본 HTML이 비었다는 이유로 자료가 없다고 처리하지 않았습니다. 100개씩 순회하며 총계가 바뀌거나 페이지가 누락되면 저장하지 않습니다. VIN은 메모리에서 중복 제거하고 버립니다. 저장하는 것은 합계·차종·중복 수·비가역 해시이며 차량 식별자는 공개 데이터 파일에 저장하지 않습니다.

공식 API에 원본 기준일이 없어 첫 정상 스냅샷 확인 시각을 그 의미와 함께 표시합니다. 같은 등록부 해시이면 원래 스냅샷 시각을 유지하고 마지막 점검 시각만 갱신합니다. 사업자 주소가 Austin이어도 주 전체 등록부를 Austin에 넣지 않습니다. [FSD Database](https://fsddb.com/robotaxi?operator=tesla-robotaxi-llc)는 같은 TxDMV 원본이므로 독립 복수 검증이 아닙니다.

[Pioneerlands](https://pioneerlands.org/cybercabtracker)의 일반 방문자 공개 익명 읽기 설정을 서버 메모리에서 발견해 **지역별 집계와 성공한 미러 시각만** 요청합니다. 공개 키·쿠키를 저장하거나 브라우저 코드에 넣지 않습니다. [원자료 집계 방법](https://robotaxitracker.com/methodology)과 별도로 구분합니다. 직접 Robotaxi Tracker API의 자동 접근 거절은 우회하지 않았습니다.

명부는 실제 배치·당일 영업의 완전한 조사와 다릅니다. `0`은 해당 차종의 **명부 기록 0건**입니다. Bay Area는 샌프란시스코시로 분리할 수 없어 광역 참고값으로만 제공하고 도시/전체 합계에서 제외합니다. 분류가 명확한 6개 지역의 명부만 기본 합계에 넣습니다. 다른 날짜의 마지막 확인값이 섞일 수 있으며 현재 확인 범위의 부분 합계입니다. 명부 증가는 생산·배치 증가로 해석하지 않습니다.

Austin 343·312는 사용자 최종 지시에 따라 차종도 미확정으로 정정하고 원래 값·최초 수집일·정정 이력을 보존했습니다. Dallas 108도 원문 403으로 미검증입니다. 이들은 모든 합계·차종 그래프·증감에서 제외합니다.

## 상태표의 의미

- 조회 성공·최초 기준 저장: 첫 문서 해시 확보, 과거 대비 변경은 아직 모름.
- 조회 성공·변경 있음/없음: **등록한 문서 내용**의 비교. 해당 주 전체에 Tesla 새 발표가 없다는 뜻이 아님.
- 차량 수 비공개: 원문이 비공개임을 확인한 경우만 사용. 단순 미추출과 다름.
- 접근 실패: HTTP 오류·연결·시간 제한.
- 추출 실패: HTTP 200 차단·로딩 전용·본문 미확인·잘못된 PDF·용량 제한 등.
- 자동 수집 미연결 / 아직 조사하지 않음: 조회 성공으로 계산하지 않음.

사이트는 오늘 실제 점검 수·성공·접근/추출 실패·문서 미연결과 **차량 수 의미 추출 연결 수**를 별도로 표시합니다. 문서 점검 연결이 차량 수 파서 연결을 뜻하지 않습니다. 현재 주별 차량 수 파서는 Texas만 연결돼 있으며 다른 50개는 미완성입니다.

공식 문서 원본 기준일은 확인되지 않으면 null을 유지합니다. HTTP 조회 시각·마지막 성공·자료 기준일을 분리합니다. 출처당 최대 2회·요청 10초, 병렬 4개, 문서 최대 12MB입니다. 큰 Oklahoma PDF는 전부 내려받지 않고 한계를 표시합니다. 일부 실패로 전체 배포를 막지 않습니다. 마지막 정상 등록부·명부·날짜·해시를 보존합니다.

## 신규 지역과 수정

`data/approved-regions.json`은 원문을 확인한 지리 사전입니다. 실제 HTTP 200 수집본에서 확인한 Coming Soon 네 도시를 원래 확인 날짜로 초기 입력했습니다. 이후 자동 요청이 403이면 이 사실과 날짜를 유지하며 실패 상태를 기록합니다. 새 지명이 공식 목록에 나타나 검증한 지리 사전과 일치하면 지도·계획 서비스·소식에 추가합니다. 검증되지 않은 지명은 지역 후보로 보관하고 임의 위치·영업 상태를 만들지 않습니다. 새 도시의 인구·가구·교통 자료가 없으면 그 도시의 한계를 표시하고 다른 도시는 계속 동작합니다.

Nevada의 Clark County 승인 상한 5,000대는 등록·배치·영업 대수가 아니므로 차량 총계에 넣지 않습니다. 해외의 FSD Supervised 소비자 기능 승인·전시 행사도 로보택시 서비스로 승격하지 않습니다.

실행: `pnpm collect`, `pnpm collect:statistics`, `pnpm scenarios`, `pnpm collect:monitoring`. 실패 모의: `node scripts/collect-monitoring.mjs --simulate-failure --dry-run`. 같은 한국 날짜 실행 기록은 하나의 일일 ID로 갱신하며 최초 소식 발견일은 유지합니다.

예약은 기존 GitHub Actions 매일 **23:00 UTC = 다음 날 08:00 KST**를 유지합니다. 개인 컴퓨터와 무관하며 정각 시작·완료는 보장되지 않습니다. 워크플로 활성·수동 실행·실제 `schedule` 이벤트의 성공은 별개로 확인합니다. 새 데이터 변경 커밋과 Pages 배포를 같은 작업에서 수행합니다.
