# 도시별 시장 잠재력 · 모델 1.0.0

이 기능은 **가정에 따른 수요 기반 추정**입니다. Tesla 배치 계획, 회사 전망, 확정 최소·최대 차량 수, 투자 수익률이 아닙니다. 실제 배치 자료와 계산 결과는 별도 파일·이력으로 유지합니다.

## 기본값과 사용 방법

도시를 고르면 공식 인구만 표시합니다. 수요·전환율·Tesla 점유율·생산성은 근거 없는 기본값을 넣지 않았으므로 처음에는 `계산 불가`입니다. `가정 편집`에서 값을 입력하면 즉시 계산합니다. `설명용 가상 입력`은 계산기 조작 확인용이며 실제 도시 자료가 아닙니다. `초기화`하면 빈 가정으로 돌아갑니다.

공식 교통 참고자료는 사용자가 버튼을 눌러 가져옵니다. 사람 단위 이동에는 동승 인원 입력이 추가로 필요합니다. 자료 범위가 행정구역과 다르면 별도 지역 ID로 유지합니다. 서비스 범위를 바꾸면 기존 수요와 기준일을 지워 잘못된 범위 재사용을 막습니다. 서비스 구역 인구는 신뢰할 지리 자료가 없어 전 도시 `미확인`입니다.

가정은 현재 브라우저의 localStorage에 도시별로 저장합니다. 서버·저장소로 전송하지 않습니다. 변경 시각·전후 가정·모델 버전을 최근 80건까지 기록하고 JSON으로 내려받을 수 있습니다. 다른 기기에는 자동 동기화하지 않습니다.

## 계산과 검증

```text
중복 없는 대상 차량 이동 = (택시·호출차 대체 + 선택한 개인차 추가 대체 + 별도 외부 수요) ÷ 동승 인원
전체 로보택시 유료 운행/일 = 대상 차량 이동 × 로보택시 전환율
Tesla 유료 운행/일 = 전체 로보택시 유료 운행 × Tesla 수요 점유율
A. 전체 필요 보유 차량 = 올림(전체 유료 운행 ÷ 전체 시장 보유 차량 생산성)
B. Tesla 필요 보유 차량 = 올림(Tesla 유료 운행 ÷ Tesla 보유 차량 생산성)
2030 대상 수요 = 기준 수요 × (1 + 사용자 연간 수요 증감률)^(2030 - 기준연도)
```

차량 운행 자료는 동승 인원으로 나누지 않습니다. 도시 인구에 임의 비율을 곱해 이동 수요를 만들지 않습니다. 미래 인구를 예측하지 않으며 2030 증감률은 통계가 아닌 사용자 가정입니다. 추가 개인차·공항·관광·통근 수요는 중복 제외 확인이 필요합니다. 이미 외부 이동을 포함하는 TfL 참고자료에는 외부 수요를 다시 더할 수 없습니다.

전체 시장과 Tesla 생산성은 별도 입력입니다. Tesla 필요 차량이 전체보다 크거나, 다른 사업자 수요가 있는데 차량이 하나도 남지 않거나, 점유율 100%에서 생산성이 다르면 오류입니다. 보수적→기준→공격적 전환율·점유율 및 차량 결과의 순서가 뒤집히면 경고하고 비교를 차단합니다. 차종 미래 비중은 빈 값이며 사용자가 선택할 때만 분할합니다.

시간 계산 도우미는 `일 운영 분 - 충전·청소·정비·기타 비가동 분`을 `유료 운행 + 픽업 + 공차 분/건`으로 나눕니다. 모든 시간은 **전체 보유 차량 1대당 평균**입니다. 추가 가동률·예비차 비율을 곱하지 않으므로 이중 적용하지 않습니다. 기간 밖 비가동 시간은 운영 시간에 넣지 말고, 겹치는 비가동 항목을 중복 입력하지 않아야 합니다. 평균 수요 계산이며 피크 대기시간을 충족하는 최소 서비스 차량 수는 계산하지 않습니다.

현재와의 비율·추가 차량은 다음이 모두 일치할 때만 계산합니다: `scopeId`, 같은 한국 날짜의 기준일, `deployed`, `vehicleDefinition=tesla_owned_fleet`, Cybercab·Model Y 두 차종의 `coverageComplete=true`. 현재 자료가 없으면 0으로 취급하지 않습니다. 2030과 현재 재고, 상업운행 차량과 전체 보유 차량, 일부 도심과 광역권 간 비교는 차단합니다. 추가 차량은 `max(0, B - 현재 배치)`이며 배치 예측이 아닙니다.

## 인구 통계

| 지역 | 검증한 자료 | 범위·기준일 | 수집 방식 |
|---|---|---|---|
| 미국 7개 도시 | Census PEP Vintage 2025 | 법정 도시·MSA 각각 2025-07-01 | 공식 CSV 자동 확인 |
| 런던 | ONS mid-2025, 9,122,909명 | Greater London E12000007, 2025-06-30 | 원문 검토 수동 입력 |
| 서울 | 서울시, 9,560,471명 | 등록 외국인 포함 행정시, 2026-06-30 | 원문 검토 수동 입력 |

Census 공식 [도시 발표 목록](https://www.census.gov/data/tables/time-series/demo/popest/2020s-total-cities-and-towns.html)·[MSA 발표 목록](https://www.census.gov/data/tables/time-series/demo/popest/2020s-total-metro-and-micro-statistical-areas.html)에서 새 빈티지 CSV를 확인합니다. 도시 SUMLEV=162 총계만 사용하며 군별 조각을 중복 합산하지 않습니다. 도시와 MSA는 더하지 않고 MSA 합계가 필요할 때 같은 지리 ID는 한 번만 계산합니다. 다른 기준일의 인구 합계는 거부합니다.

런던은 [공식 Nomis 지역 보고서](https://www.nomisweb.co.uk/reports/lmp/gor/2013265927/report.aspx)와 [ONS mid-2025 발표](https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationestimates/bulletins/populationestimatesforenglandandwales/mid2025)를 확인했습니다. City of London 자치구와 다릅니다. 별도 광역권 인구는 미확인입니다.

서울은 [서울시 인구 페이지](https://english.seoul.go.kr/seoul-views/meaning-of-seoul/4-population/)에서 검증한 2분기 값입니다. 더 최신 [2026년 8월 통계 발표](https://data.seoul.go.kr/dataService/statView.do?pageIndex=1&wjId=c3781c51238afda889813e9dd8b3a140)의 동적 표 수치 추출은 미연결이므로 최신 발표치라고 주장하지 않습니다. 광역권 인구도 미확인입니다.

## 교통 자료와 빈칸

- 런던: [TfL Travel in London 2025, Table 1](https://content.tfl.gov.uk/travel-in-london-2025-consolidated-estimates-of-total-travel-and-mode-shares-acc.pdf)의 **2024년 사람 이동 약 40만 건/일**. 반올림된 7일 평균이며 출발·도착 중 하나 이상이 Greater London인 범위입니다. 방문객·통근 이동을 포함합니다. 차량 건수가 아니므로 동승 인원이 필요하고, 행정구역 내부 수요와 동일하게 비교하지 않습니다.
- 서울: [서울시 택시 운행 현황](https://news.seoul.go.kr/traffic/archives/307)의 **2026-01-31 기준 781,765건/일, 평균 유료 시간 18.9분**. 서울 등록 택시 실적이며 모든 운행이 행정시 안에서 발생한 것인지는 미확인입니다. 참고 버튼으로만 가져오고 지역 ID를 행정시와 분리합니다.
- 샌프란시스코: [SFCTA 2017 연구](https://www.sfcta.org/projects/tncs-today-2017)는 2016년 평일 자료이므로 현재 수요 기본값으로 사용하지 않습니다. 최신 검증 일일 총수요는 미확보입니다.
- 다른 미국 도시: 최신 도시 전체 택시·호출차 일일 수요를 검증하지 못했습니다. 전국 평균이나 임의 인구 비율로 대체하지 않습니다. 사용자가 출처와 범위를 확인한 가정을 입력해 계산할 수 있습니다.

## 갱신과 수동 정정

차량 수집은 매일 한국시간 08시 GitHub Actions, Census 통계 확인은 같은 작업 안에서 **최근 확인 후 7일**이 지났을 때 진행합니다. Run workflow의 `refresh_statistics`로 즉시 재확인할 수 있습니다. 일별 재실행이 통계 기준일을 갱신하지 않습니다. 새 수치·빈티지가 있을 때만 `statistics.json`에 정정 이력과 변경 시각을 기록하고 최초 수집일은 보존합니다.

통계 요청은 15초 제한, 최대 2회입니다. 401·403·404는 재시도하지 않습니다. 실패하면 해당 인구를 마지막 정상값으로 유지하며 계산기와 다른 도시 수집은 계속 작동합니다. 발표 목록이 막혀도 마지막 확인한 공식 CSV를 시도하고 한계를 상태 메시지에 남깁니다.

런던·서울 인구와 교통 참고자료는 `data/statistics-manual.json`을 수정합니다. 자동 Census 수집은 해당 지역을 덮어쓰지 않습니다. 통계 수정 이력은 `public/data/statistics.json`, 모델 변경은 `public/data/market-model.json`, 브라우저 가정 변경은 localStorage로 구분하며 과거 차량 스냅샷은 건드리지 않습니다. 별도 비밀키·유료 API는 필요 없습니다.
