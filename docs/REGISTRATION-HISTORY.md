첫 화면은 TxDMV 직접 조회 기록의 KST 날짜별 마지막 확인값으로 Cybercab과 Model Y의 하루 순증감을 따로 표시한다. 직전 달력 날짜의 자료가 없으면 하루 증감은 null이고 실제 확인된 변동 없음만0이다. 여러 날 간격 변화는 상세표에서만 보여준다. 오늘 수치는 최근 확인 시점까지이며 최종 일일값이 아니다.

FSD Database 공개 JSON의 Tesla 사업자 일별 등록 총계는 별도 민간 재집계 그래프로 보존한다. 최초 확보2026-10-28T08:03:31.055Z, 출처 날짜2026-06-09–2026-10-28, 132개 확인값. 출처 날짜의 시간대 및 과거 차종 구분은 미공개다. 7월31일–8월9일은 수치 없는 날짜로 둔다. 공식 KST 스냅샷과 합산하거나 평균내지 않는다.

수집기는 공식 현재 대수, 민간 현재 총계, 과거 시계열을 독립 검증한다. 과거 구조가 변경되어도 현재 대수 수집은 유지하고, 실패 시 마지막 정상 과거값·기준일을 유지한다. 과거 정정은 revisions에 이전/교체값·확인시각을 남긴다. 공개 JSON 중 집계값만 저장하며 VIN·개별 위치는 저장하지 않는다.

날짜·차종 필터와7/30/90/전체 기간, 누적/증감 전환, CSV/PNG 저장을 제공한다. CSV 공백은 미확인이고0은 확인된 변동 없음이다.
