## 채택: Texas Autonomous Fleet Tracker의 당시 명부 스냅샷

- 페이지: https://texasavtracker.com/tesla
- 공개 API: https://texasavtracker.com/api/data?brand=tesla
- HTTP 200. 응답의 history는 각각 timestamp, count, 당시 명부 배열을 제공한다. 현재 명부 최초 발견일을 역산한 선과 다르다.
- 각 당시 명부의 고정 차량 속성을 현재 vehicles의 **명시적 model 필드**와 메모리에서 대조한다. 모델명 대소문자·공백만 정규화하며 접두어로 모델을 추측하지 않는다.
- 저장 결과는 일별 합계·모델 집계·시각·방법·집계값 해시뿐이다. 원본 명부·차량 식별자·개별 위치·개별 식별자 해시는 저장하거나 로그로 출력하지 않는다.
- 이는 원기관이 직접 제공한 모델 시계열이 아니라 **비공식 과거 스냅샷에서 파생한 모델 집계**다. verification=unofficial, basis=registered, scope=US-TX.
- 같은 **UTC 날짜**의 마지막 실제 스냅샷을 채택한다. 미국 현지 일자나 기존 공식 KST 관측일과 혼용하지 않는다. publishedAt은 미공개이므로 null이다.
- 6/9 이후 실제 스냅샷29일 중 최초 조사에서24일의 모델 대조를 완료했고5일은 모델1건 미매핑으로 보존했다. 추가 조사에서 당시 단일차종 전체 명부를 명시한 기사를 확보해 폐쇄집합 근거로5일을 보완했다(아래 추가 보완 절 참조). 공식 확인으로 승격하지 않는다.
- 당시 명부 길이와 원본 총계가 다르거나 명부가 없으면 모델 값은 null이다. 완전한 당시 명부에서 해당 모델이 없을 때의 0만 채택한다. 이는 **등록 스냅샷 내 해당 모델 0건**이지 실제 영업 차량 0대라는 뜻이 아니다.
- 결측일 보간·현재 값의 소급 적용·미수집 날짜의 0 채움·매일 확인한 것처럼 날짜 생성은 하지 않는다.
- 수집 실행 확인 시각은 lastCheckedAt이고 실제 과거 스냅샷 시각은 observedAt이다. 최초 수집일 firstCollectedAt을 재실행으로 바꾸지 않는다.
- 제공 창이 줄어도 이미 확보한 과거는 유지한다. 현재 명부에서 모델 매핑이 사라져도 동일 과거 스냅샷(기준 시각·총계·전체 명부 단일 해시 동일)의 이전 검증 모델 분할을 보존하며, 현재 매핑 누락 안내는 validationNote로 구분한다. 전체 명부 단일 해시는 변경 여부만 검증하며 개별 식별자 해시는 저장하지 않는다. 정정 시 집계 전후 값을 revisions에 남긴다. HTTP 401/403/404는 재시도하지 않고, 나머지 오류는 최대 두 번·각 15초로 제한한다. 실패 시 기존 정상 숫자와 수치 기준일을 보존한다.

### 출처의 uncertain 표시 뜻

원본 /tesla 화면은 uncertain 항목을 **“After source gap”**으로 표시하며, 실제 등록일을 알 수 없고 정부 원본 복구 뒤 처음 발견했다는 설명을 제공한다. 따라서 이 필드는 당시 스냅샷에서 차량이 존재했는지 불확실하다는 뜻이 아니다. 당시 완전한 명부와 명시적 모델 매핑이 있으면 관측일의 재고 집계에 포함하되, 실제 등록 발생일은 미상이라고 note에 남긴다. 해당 간격의 증가분을 특정 날짜의 신규 제조·등록·배치로 단정하지 않는다.

### 6/9 총계 충돌

이 출처의 2026-06-09T16:01:27.815Z 스냅샷은 59대다. FSD Database/Aeronaut의 6/9 달력 날짜 총계 69와 다르다. 시간대·관측 시각·과거 수집 방식이 다른 자료를 평균내거나, 이 자료의 Model Y에 10대를 보태서 69로 맞추면 안 된다. 별도 출처 시리즈로 보존하고 충돌을 명시한다.

## 미채택: Robotaxi Tracker 화면의 과거 차종선 전체 복사

- 페이지: https://robotaxitracker.com/permits/texas
- 조사 시 공개 UI 자산: /assets/txDmvModels-D4tx0BnE.js, /assets/txDmvHistory-CktF7SNz.js, /assets/TexasPermitsPage-CY52xTyi.js.
- 화면의 차종별 선은 보존된 과거 모델별 집계 행을 그대로 그리는 방식이 아니다. 각 식별자의 first_seen/last_seen 및 현재 모델 또는 식별자 접두어 fallback으로 역산한다.
- 계산된 모델 합계가 당시 총계와 다르면 **가장 큰 모델 집계에 차이를 더해 총계와 강제로 일치**시키는 보정이 있다. 이 보정으로 만든 매일의 모델 대수를 실제 날짜별 모델 스냅샷으로 복사하면 안 된다.
- 원본 집계 API /v1/api/texas-dmv는 HTTP 403으로 **자동 접근 불허**를 명시했다. 헤더 변경·우회·재시도 없이 중단했다. 키 생성이나 인증 시도는 하지 않았다.
- 원본 추적자의 방법론 설명은 당시 보도의 근거로 사용할 수 있으나, 실제 과거 날짜별 게시 숫자는 원문에서 따로 확인해야 한다.
