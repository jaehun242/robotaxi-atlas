## 브라우저 조작

세계→미국→텍사스→오스틴, 필터·마커·도시 인구·시장 패널 연동을 확인했습니다. 설명용 가정을 명시적으로 선택하면 A=400/1,200/2,400, B=34/200/600으로 계산됩니다. 기준 Tesla 생산성만 30→25로 바꾸면 B=240이 되고 A=1,200은 유지됩니다. 테스트 후 가정은 초기화했습니다. 이 수치는 검증용 가상 입력이며 실제 도시 전망이 아닙니다.

런던 TfL 참고자료 선택 후 동승 인원 미입력 시 계산이 차단되고 입력 시 환산됨을 확인했습니다. 이미 포함된 외부 수요를 추가하면 거부하며, 공격적 시나리오 결과가 기준보다 작아지면 경고합니다. 모바일 크기에서 가정 편집·초기화·계산 근거 패널도 조작했습니다.

## 화면 크기 모의 검사

설정한 크기(CSS px): 320×568, 360×800, 390×844, 800×360, 844×390, 768×1024, 1024×768, 1440×1000. 데스크톱 스크롤바로 실제 콘텐츠 폭은 15px 작았습니다. 가정 편집을 펼친 상태에서도 모든 크기에서 문서 scrollWidth=clientWidth로 가로 넘침이 없었습니다. 작은 화면은 표가 라벨 있는 카드로 전환되고 지도 캔버스 높이가 컨테이너와 일치했습니다. 모바일·태블릿의 주요 버튼·필터·마커 조작 영역은 44px 이상, 입력 글자는 16px입니다.

브라우저 포인터 클릭으로 탭에 해당하는 단일 선택과 입력 동작을 확인했습니다. 도구가 실제 터치 이벤트·모바일 브라우저 엔진·멀티터치 모의를 제공하지 않아 해당 검사는 하지 않았습니다. **실제 아이폰·안드로이드 기기 검사는 미실시**입니다. 위 크기는 기기의 세로·가로에 해당하는 뷰포트 모의이며 실제 Safari/Chrome 기기 검증을 대체하지 않습니다.

실기기에서 추가 확인하려면 공개 주소를 Safari/Chrome으로 열고 세로·가로 회전 → 필터 선택 → 오스틴 마커 → 인구·시장 가정 편집 → 초기화 → 그래프 PNG 저장을 확인하면 됩니다.
